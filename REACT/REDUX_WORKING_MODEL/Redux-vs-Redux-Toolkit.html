Feature Comparison

Greeting feature — same behaviour, different files.

Vanilla Redux

redux + react-redux
redux/
  greetingActions.js ← you write types + creators
  greetingReducer.js ← switch/case reducer
  store.js
Action type'greeting/SET_NAME'
Update state{ ...state, name: payload }
Import in UIfrom '../redux/greetingActions'
// greetingActions.js
export const SET_NAME = 'greeting/SET_NAME'
export const setName = (name) => ({
  type: SET_NAME, payload: name
})

Redux Toolkit

@reduxjs/toolkit + react-redux
redux/
  greetingSlice.js ← all-in-one
  store.js
Action type'greeting/setName' (auto)
Update statestate.name = payload
Import in UIfrom '../redux/greetingSlice'
// greetingSlice.js
const slice = createSlice({
  name: 'greeting',
  initialState: { name: 'World' },
  reducers: {
    setName: (state, action) => {
      state.name = action.payload
    }
  }
})
export const { setName } = slice.actions
