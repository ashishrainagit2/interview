1. Create the Vite + React app (JavaScript)
npm create vite@latest redux-react-demo-with-toolkit -- --template react

2. Go into the project folder
cd redux-react-demo

3. Install base dependencies
npm install

4. Install Redux packages
npm install redux react-redux

5. Run the app (development)
npm run dev

6. install toolkit
npm install @reduxjs/toolkit react-redux

Optional / useful commands

Build for production
npm run build

Preview production build locally
npm run preview

Run ESLint
npm run lint
