CONTAINER PROPERTY

1. display - flex | inline-flex - default: none (must be set)

2. flex-direction - row (default) | row-reverse | column | column-reverse - Sets the display-direction of flex items

3. flex-wrap - nowrap (default) | wrap | wrap-reverse - Specifies whether the flex items should wrap or not

4. flex-flow - row nowrap (default) |  |  - Shorthand property for flex-direction and flex-wrap

5. justify-content - flex-start (default) | flex-end | center | space-between | space-around | space-evenly - Aligns the flex items when they do not use all available space on the main-axis (horizontally)

6. align-items - stretch (default) | flex-start | flex-end | center | baseline - Aligns the flex items when they do not use all available space on the cross-axis (vertically)

7. align-content - stretch (default) | flex-start | flex-end | center | space-between | space-around - Aligns the flex lines when there is extra space in the cross axis and flex items wrap.

Nemonics: "Dude, Direction Wrong? Just Align Items And Chill."

Dude = Display
Direction = Flex-Direction
Wrong = Flex-Wrap
Just = Justify-Content
Align and= Align-Items 
Chill = Align-Content


    ITEM PROPERTY
    1. order - 0 (default) |  - Specifies the order of the flex item.
    2. flex-grow - 0 (default) |  - Specifies the flex grow factor of the flex item.
    3. flex-shrink - 1 (default) |  - Specifies the flex shrink factor of the flex item.
    4. flex-basis - auto (default) |  - Specifies the initial main size of the flex item.
    5. flex - 0 1 auto (default) |    - Shorthand property for flex-grow, flex-shrink and flex-basis.
    6. align-self - auto (default) | flex-start | flex-end | center | baseline | stretch - Specifies the alignment of the flex item.

    Nemonics: "One Guy Shrinks Before Aligning Self."

        One = Order
        Guy = Grow
        Shrinks = Shrink
        Before = Basis
        Align Self = Align-Self
